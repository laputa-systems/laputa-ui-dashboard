# AffectUI catalog and gap matrix

Companion to the [implementation plan](affectui-plan.md). Research snapshot: **2026-11-09**. Baseline: [`2fd9866c2ef28e27815cb6586bf65e31a96013d1`](https://github.com/laputa-systems/laputa-ui-dashboard/commit/2fd9866c2ef28e27815cb6586bf65e31a96013d1), `@laputa-systems/ui-dashboard` 0.5.0.

This is the exhaustive snapshot checklist: **90 components + 34 screens + 14 blocks + 8 motion effects + 26 illustrations = 172 items**. Public detail documentation was read for the first four sections; illustrations were enumerated, with Model Wheel and Voice Orb studied for functional overlap. Representative previews were visually inspected, not exhaustively tested. Sources can change after this date.

The first screens index returned 33; the refreshed index and browser included AI Chat / Progress, bringing the audited count to 34. Include it even if an older cached index omits it.

## How to use this matrix

- **Baseline** describes the actual repository before implementation. `New` means no equivalent behavior exists; composing existing Button/Panel/Badge styling does not make an advanced workflow implemented. `Partial` names the useful existing subset.
- **Destination** is a proposed module or recipe, not a promise to export every reference name. Family paths are conceptual until P0 establishes package boundaries. Navigation/feedback primitives can live within the relevant forms/layout subpath; examples are not mandatory runtime dependencies.
- **Phase** uses P0-P9 from the main plan. P9 is separately scoped work gated on a concrete consumer; explicitly deferred art/motion stays outside default production coverage. A phase number is not a completion status.
- **Acceptance** combines the useful documented design with original Laputa requirements. It does not assert that the reference implements every production safeguard listed. Global state, keyboard, layout, package and validation requirements in the main plan apply to every row.
- **All rows are planned or explicitly deferred.** When implemented, append source/recipe, fixture and test evidence to the row or a linked tracking note; do not erase the baseline. A backend adapter can remain unavailable even after its presentation exists.
- Screens and blocks are coordinated recipes. Build shared primitives once, then demonstrate each distinct composition. CSS-only equivalents are required where useful; do not pretend CSS supplies live editing, drag/drop, scheduling or approvals.
